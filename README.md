# CyberLens – Cyber Intelligence & Compliance Platform

CyberLens is an NLP-based data analytics platform for analysing cybersecurity and threat intelligence data. It combines text analysis, classification, entity extraction, summarization, and explainable risk analysis into a unified workflow.

# Key Features

- Text & Threat Analysis – Extracts cybersecurity entities and analyses threat intelligence reports using NLP.
- Data Classification – Uses TF-IDF, Logistic Regression, and Linear SVM for threat classification.
- Entity Extraction – Uses BERT to identify threat actors, malware, tools, vulnerabilities, and attack activities.
- Text Summarization – Uses DistilBART to generate concise summaries from lengthy reports.
- Data Insights – Combines outputs from multiple analytical modules to generate risk assessments and recommendations.
- Database & Dashboard – Stores analysis results in PostgreSQL and presents insights through Streamlit dashboards.

# Technologies

Python | NLP | Pandas | NumPy | Scikit-learn | PyTorch | BERT | DistilBART | SQL | PostgreSQL | Streamlit
